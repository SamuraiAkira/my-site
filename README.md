# Как запустить 3d сцену?

### Установка зависимостей

Нужен лишь **Python**

### Запуск проекта

1. Перейти в папку проекта

```
cd path\to\project
```

2. Перейти в папку сцены

```
cd 3d-scene
```

3. Запустить локальный сервер на свободном порту

```
python -m http.server 8000
```

4. Открыть страницу в браузере

```
http://localhost:8000
```
